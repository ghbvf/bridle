# Publishing Guide

How to deploy this repo to `https://ghbvf.github.io/bridle/` and make it discoverable on Google / Bing / GitHub search.

---

## 1. Push to GitHub

```bash
cd /path/to/methodology
git init
git add -A
git commit -m "Initial commit: Bridle methodology v7"
git branch -M main
git remote add origin https://github.com/ghbvf/bridle.git
git push -u origin main
```

---

## 2. Enable GitHub Pages

1. Go to `https://github.com/ghbvf/bridle/settings/pages`
2. **Source**: Deploy from a branch
3. **Branch**: `main` · `/ (root)`
4. Click **Save**
5. Wait ~1 minute. Site will be live at `https://ghbvf.github.io/bridle/`.

What renders:

| Path | URL |
|---|---|
| `README.md` | `https://ghbvf.github.io/bridle/` |
| `three-leaps.md` | `https://ghbvf.github.io/bridle/three-leaps/` |
| `three-leaps.en.md` | `https://ghbvf.github.io/bridle/en/three-leaps/` |
| `three-leaps-bootstrap.md` | `https://ghbvf.github.io/bridle/three-leaps-bootstrap/` |
| `three-leaps-bootstrap.en.md` | `https://ghbvf.github.io/bridle/en/three-leaps-bootstrap/` |
| `deck/index.html` | `https://ghbvf.github.io/bridle/deck/` |
| `deck/en/index.html` | `https://ghbvf.github.io/bridle/deck/en/` |

  agent-harness · declarative · devops · sre

## 4. Submit to search engines

### Google Search Console

1. `https://search.google.com/search-console`
2. Add property: `https://ghbvf.github.io/bridle/`
3. Verify via HTML file (download verification file → place in repo root → push → re-verify)
4. Submit sitemap: `sitemap.xml` (auto-generated by `jekyll-sitemap`)

### Bing Webmaster Tools

1. `https://www.bing.com/webmasters`
2. Add site `https://ghbvf.github.io/bridle/`
3. Import from Google Search Console (one-click)

### Indexing speed

- Google: typically 2–14 days; sitemap submission accelerates
- Bing: typically 1–7 days
- DuckDuckGo: piggybacks on Bing, no separate submission needed

## 5. Enable jekyll-seo-tag

Already configured in `_config.yml`. Each page automatically renders:

- `<meta name="description">` from front-matter
- `<meta name="keywords">` from front-matter
- Open Graph tags (og:title, og:description, og:image)
- Twitter Card tags
- JSON-LD structured data
- Canonical link
- Hreflang for zh-CN ↔ en pages (manually link via cross-references)

## 6. Verify locally (optional)

```bash
gem install bundler jekyll
bundle init
echo 'gem "github-pages", group: :jekyll_plugins' >> Gemfile
bundle install
bundle exec jekyll serve
# Visit http://localhost:4000/bridle/
```

## 7. Custom domain (optional)

If you own e.g. `bridle.dev`:

1. Create file `CNAME` in repo root containing `bridle.dev`
2. At your DNS provider, add CNAME `bridle.dev` → `ghbvf.github.io`
3. In `Settings → Pages → Custom domain`, enter `bridle.dev`
4. Wait for DNS propagation; enable "Enforce HTTPS"
5. Update `_config.yml` `url` field accordingly
